# 墨生 InkFlow

> 状态：Private 持续开发；当前主线候选 V1.17；V1.14 保留为稳定视觉基线。

## 项目定位

墨生（InkFlow）是一款可离线运行的水墨山水与生态演化体验。项目将纸面水墨扩散、山水地形、水文过程、植被演替和动物行为整合到同一个可交互世界中。

## 架构与运行方式

- 单文件 HTML 主程序，Canvas 负责纸面水墨与二维表现。
- WebGL 负责三维山水地形与生态可视化；源码包含软件渲染回退路径。
- 生态模拟使用确定性随机种子，便于复现实验。
- 无需生成式 AI API；当前主程序不依赖外部 CDN 脚本。
- 使用现代桌面浏览器打开 `InkFlow_V1.17.html`。建议启用 WebGL。

## 验证纪律

- 未经验收的功能不得标记为完成。
- 合成数据结果、初始地形公式镜像测试、完整生态仿真和浏览器验收必须分开报告。
- 不因一次失败或单个种子异常就推断为系统性缺陷；先复现并控制变量。
- 每个版本保留可复现源码、测试脚本、结果和变更说明。
- V1.14、V1.15、V1.16 及历史版本不覆盖，后续版本以新增快照方式归档。
