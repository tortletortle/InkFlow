# InkFlow V1.16 — 山脊像素皴与方向场连续性

## 研发目标

V1.15 已将 Hessian 山脊方向估计接入地形顶点颜色，但 GPU 片元着色器仍叠加各向同性纹理，方向场没有直接参与像素级材质生成。本版本把方向场作为独立顶点属性传入 GPU，并让软件渲染回退路径使用相同方向数据。

## 核心变更

1. **双角度轴线编码**：将方向向量编码为 `(cos(2θ), sin(2θ)))，消除 Hessian 特征向量的正负号歧义，避免插值时因 `n` 与 `-n` 抵消而丢失方向。
2. **GPU 片元级顺势皴**：新增 `aRidge/vRidge` 属性，在片元着色器中恢复山脊法线与切线，沿法线快速变化、沿切线缓慢变化，生成方向性纹理。
3. **符号不变纹理**：纹理噪声对 `(across, along)` 与其相反坐标取对称平均，保证轴线正反等价。
4. **统一顶点布局**：网格从 9 个浮点数扩展为 12 个浮点数：位置 3、法线 3、颜色 3、山脊轴线与置信度 3。非地形网格默认写入零方向。
5. **软件回退一致性**：软件光栅器插值同一方向场，并在像素级计算顺势皴，不再丢失 V1.15 的山脊材质特征。
6. **避免双重叠加**：地形顶点颜色只保留基础岩石洗染，方向皴纹由 GPU 片元着色器或软件像素路径单独生成。

## 回归验证

复现实验：

```bash
node research/v1.16/ridge-shader-pipeline.js
```

测试脚本从 V1.16 生产 HTML 中提取方向场纯函数，并对以下项目进行断言：

- 72 组直线山脊方向恢复；
- 弯曲山脊方向恢复；
- 30 组初始地形公式镜像测试；
- 平坦低幅度噪声拒识；
- 特征向量正负号编码一致性；
- 方向皴纹对轴线正反方向的不变性；
- GPU 顶点属性与片元着色器接线；
- 软件渲染回退路径的方向场插值与像素级皴纹；
- 方向纹理幅度和非有限数值。

## 关键数值结果

| 项目 | 结果 |
|---|---:|
| 直线山脊方向样本 | 6,216 |
| 直线山脊平均角度误差 | 0.283° |
| 直线山脊 P90 误差 | 0.635° |
| 弯曲山脊方向样本 | 306 |
| 弯曲山脊平均角度误差 | 0.534° |
| 现有初始地形公式镜像测试 | 30 组 |
| 地形方向场非有限值 | 0 |
| 双角度正反编码误差 | 0（浮点精度内） |
| 方向纹理正反不变误差 | 0（浮点精度内） |

代表性地形（seed 27、40×26）的 196 个有效山脊样本中，CPU 方向皴纹标准差约为基础岩石洗染的 36.9%，组合材质标准差增加 4.6%。这只是数值对比校准，不等于视觉质量提升。

## 验收边界

**脚本已验证：** JavaScript 语法、方向场数值、双角度编码、CPU 方向纹理、生产源码接线和软件路径静态集成。

**仍需真实浏览器验证：** WebGL GLSL 编译、GPU 画面观感、软件回退截图、不同 GPU 的兼容性、帧率与长时间生态运行。当前没有连接的浏览器标签页，因此不把静态接线检查冒充为真实 GPU 渲染验收。
