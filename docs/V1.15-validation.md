# InkFlow V1.15 — 山脊顺势皴

## 本次变更

V1.15 将此前 V1.15 研究目录中的 Hessian 山脊方向估计，从独立合成实验推进到 3D 地形材质管线：

- 对地形高度场做可分离高斯平滑（默认 sigma = 1.3 个网格单元）。
- 在世界坐标尺度上计算二阶导数与 Hessian。
- 选择绝对值最大的 Hessian 特征值对应方向，作为山脊横向法线。
- 仅在凸脊、方向各向异性和曲率强度达到门限时输出置信度。
- 通过沿法线快速变化、沿山脊切线缓慢变化的低幅度噪声，生成顺着山脊走向的水墨皴纹。
- 方向皴纹经对比度校准，函数理论幅度上限约 ±0.05；在代表性初始地形（seed 27、40×26）的 196 个有效山脊样本上，方向项标准差约为基础岩石洗染的 51.3%，合成材质标准差增加 11.2%；坡度来自生产网格法线计算，不改变生态高度场、水量、侵蚀或植被模拟。

V1.14 文件保持不变，作为对照基线。V1.15 是新增的主线候选版本。

复现实验：

```bash
node research/v1.15/terrain-ridge-integration.js
```

该脚本直接从 `InkFlow_V1.15.html` 提取生产代码中的纯函数，避免测试实现与游戏实现分叉。

## 证据边界

**已验证：**
- 合成直线与弯曲山脊的方向恢复精度。
- 现有 `EcoSim._buildTerrain` 初始高度场公式在两种网格分辨率、三种地形布局和五个种子下的数值稳定性。
- 平坦低幅度噪声不会生成方向场。
- 方向皴纹幅度受控且无 NaN/Infinity。

**尚未验证：**
- 浏览器中的实际画面是否比 V1.14 更自然、更接近传统山水皴法。
- WebGL 与软件回退路径的实际渲染一致性。
- 长时间生态演化下的画面稳定性。
- 低端 GPU 的帧率影响。

因此，不能仅凭方向误差就宣称画面艺术质量已经提升；还需要浏览器截图对照和性能实测。
