# InkFlow V1.17 — 自适应山脊场与性能优化

## 为什么需要 V1.17

V1.16 把山脊轴线作为独立顶点属性传入 WebGL 片元着色器，并为软件回退实现像素级方向皴纹。但全分辨率 Hessian 方向场计算在较大生态网格上开销偏高。V1.17 优化平滑卷积、对方向场降采样计算并插值回原网格，同时对方向场做短时缓存。

## 实现

- 将高斯平滑改为可分离的 7-tap（半径 3）卷积，减少边界函数调用和临时写入。
- 方向场在受限粗网格上计算，双角度轴线使用双线性插值；插值向量长度用于折减置信度，抑制方向分歧处的伪皴纹。
- 生态网格 120×75 使用 60×38 的山脊计算网格；240×150 使用 80×50。
- 同一生态实例的山脊方向场每 0.6 个模拟时间单位刷新；种子、分辨率、生态对象或表面修订变化，以及强制更新时会立即重算。
- 地形几何和生态状态仍按原逻辑更新；缓存只作用于装饰性山脊方向场。

## 数值质量验证

测试将自适应方向场与同一高度场上的全分辨率方向场进行对照，共 30 组：两种网格分辨率、三种地形布局、五个随机种子。

| 指标 | 结果 |
|---|---:|
| 自适应方向覆盖率最小值 | 85.0% |
| 自适应方向覆盖率平均值 | 87.22% |
| 与全分辨率有效方向重叠率最小值 | 74.8% |
| 重叠率平均值 | 76.19% |
| 匹配样本平均轴线角度偏差 | 5.17° |
| 匹配样本整体 P90 偏差 | 11.94° |
| 最差单组 P90 偏差 | 12.62° |
| 大于 30° 的偏差样本 | 0.179% |
| 最大局部偏差 | 89.12° |
| 非有限值 | 0 |

最大局部偏差仍然存在，虽然只占 0.179% 的匹配样本，但尚未做空间分布归因。它们可能影响局部山脊交汇处的纹理连续性，需要视觉验收继续检查。覆盖率是阈值置信度统计，不等同于艺术质量评分。

## 性能基准

在当前隔离 JavaScript 执行环境中，以相同 seed 27 的地形分别测量全分辨率与自适应计算，取 11 次运行的中位数：

| 生态网格 | 全分辨率计算 | 自适应计算 | 加速比 |
|---|---:|---:|---:|
| 120×75 | 20 ms | 10 ms（60×38） | 2.00× |
| 240×150 | 84 ms | 31 ms（80×50） | 2.71× |

测试环境使用 `Date.now()`，数据会受执行环境、JIT 预热与机器负载影响；这不是浏览器帧率测试，也不是目标设备性能承诺。0.6 个模拟时间单位刷新一次的缓存用于进一步降低长期平均开销。

## 复现

```bash
node research/v1.17/ridge-adaptive-performance.js
```

脚本从 V1.17 生产 HTML 提取方向场算法，执行直线/弯曲山脊测试、30 组自适应与全分辨率对照、符号连续性、平坦噪声拒识、GPU/软件渲染接线与小网格旁路测试。

- V1.14、V1.16、V1.17 同种子同相机截图对照。
- GPU 与软件回退画面一致性。
- 真实设备帧率、GPU 占用和长时间生态演化回归。
- 大角度偏差样本的空间位置分类与局部置信度策略优化。

因此 V1.17 目前是性能优化后的主线候选，不是已完成视觉验收的稳定发布。
